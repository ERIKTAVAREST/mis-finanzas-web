# Carpeta de APKs para descarga Web

Coloca aquí tus archivos .apk compilados desde Android Studio.
Por ejemplo:
- MisFinanzas-1.1.2.2-debug.apk

Cuando compilas desde Android Studio, el archivo `android/app/build.gradle` está configurado para copiar automáticamente el APK compilado a esta carpeta.
Desde la versión web (https://eriktavarest.github.io/mis-finanzas-web) los usuarios podrán descargarlo directamente desde Ajustes > Sistema.
